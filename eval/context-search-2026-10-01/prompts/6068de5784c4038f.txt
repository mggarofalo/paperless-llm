Treat every page as independent visual evidence. For each page-specific identifier, footer, endorsement code and repeated panel, verify every character against that exact page and physical region. Never copy a neighboring page code to fill a small, faint or missing span, even when the layout is identical or a sequence seems predictable. Similar text elsewhere is only a reason to recheck the source, never evidence for this instance. Before final assembly, compare each page first and last text blocks and all repeated-panel identifiers to its own image; preserve differences and required repeated instances. If any actual text remains unreadable, apply the unchanged OCR keep rule and identify the page/span.

This task includes complete transcription when the source is readable. Document length, many rows, small font, or the absence of old OCR are not themselves unreadability. Allocate the response budget to literal page text and finish all supplied pages. Never use a generic claim that there is too much text as a substitute for attempting the transcription. If an actual source span remains unreadable, apply the existing keep policy and identify it precisely.

Track text instances by their physical source position. Repeated rows, repeated cards and repeated footer text are separate instances that must remain in a complete transcription. Overlapping crops show the same physical instance more than once, so assemble it only once. Deduplicate overlap by location, never by matching text alone.

For a machine-readable identifier line, distinguish actual digit glyphs from transit, on-us and other separator symbols. Preserve visible leading zeros and field boundaries; do not convert separators into extra digits. Independently read each field from the image. Expected digit counts and familiar number formats are only discrepancy checks and never a source of replacement characters.

For an OCR keep decision caused by source uncertainty, use the existing top-level uncertainty field to name the page, physical region and character-level problem; include a short readable neighboring label when possible. Reinspect every supplied view of that same span before deciding. Distinguish unreadable text from a genuinely blank field and from a nontext graphic. Do not guess the uncertain characters. An already-faithful current OCR can be kept without fabricating an unreadable span.
